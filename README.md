A game that pulls from Heroes, Dungeons&Dragons (D&D), jRPG games, and old dungeon crawler games.
The game is going to be a series of more or less randomized dungeons which are connected via a simple story line.
Player will be able to move on the overworld similarly to Heroes 3 or jRPG games and then enter a location that resembles a dunegon build on a 1x1 grid. 
During the dungeon the games switches to a Tactical view where player's heroes are to explore the map and slay enemies in turns. Each character would roll an initiative in the turn order similarly to Dungeons&Dragons
with mechanics like range and melee attacks, magic and later item use all inspired by D&D.

So far the game is in development with the tactical camera and grid system with A* pathfinding implemented.
